# Culture Kicks — Vadodara's Premier Sneaker Storefront

An immersive, high-performance D2C e-commerce storefront prototype built for **Culture Kicks** ([@culturkicks.store](https://www.instagram.com/culturkicks.store/)), located at 105 Aries Prime, Vasna Main Rd, Vadodara, Gujarat.

## Features
- **Cinematic Looping Video Hero:** Edge-to-edge 3D-feeling sneaker loop with dynamic colorway overlays.
- **Curated Hype & Grail Catalog:** Featuring Travis Scott x Fragment Jordan 1 Low, On Cloudmonster 2, Air Jordan 4 Bred, Dunks, Sambas, and New Balance 9060.
- **Interactive 3D Sneaker Lab:** 360° product inspection with real-time controls.
- **Full E-Commerce Demo Flow:**
  - Slide-out Cart Drawer with free delivery progress bar.
  - Promo code integration (`CULTURE10` for 10% VIP discount).
  - 3-Step Demo Checkout (Address → Dispatch → Payment) with confetti celebration.
  - Persistent Wishlist Archive with local storage.
  - Live search modal with instant suggestions.
  - Working UK/US/EU size converter guide.
- **Local Store & Social Proof:** Direct WhatsApp concierge (+91 8866059560), Google Maps directions, and Instagram feed integration.

## Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
